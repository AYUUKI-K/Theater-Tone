# 小剧场换色

SillyTavern 扩展。先点屏幕边缘的小把手展开浮球，再点浮球按酒馆当前主题给最新楼层的小剧场切换亮暗配色。展开时再点一次可恢复原色。

## 安装

在酒馆打开「扩展 → 安装扩展」，粘贴仓库地址，安装后刷新页面。

```text
https://github.com/AYUUKI-K/Theater-Tone.git
```

已安装旧版时，在「管理扩展」中点「小剧场换色」这一行的下载箭头，再刷新页面。也可以在酒馆的扩展面板展开「小剧场换色」，点「立即换色」。

## 使用

- 浮球只检查当前存档的最后一条消息。若最后一条是普通文字，会提示没有可改色的 HTML。
- 支持酒馆助手已经加载的 HTML iframe，以及直接渲染在消息里的着色 HTML 块。插件按背景面积估算主色调，从当前主题的聊天背景、文字、引用色和界面边框取色，调整浅色和深色的对比度。改色保留原有布局和媒体。
- 展开后可以拖动浮球，松手后会收进最近的左右边缘，刷新后会记住位置。点聊天区或闲置约 4 秒也会收起。扩展面板提供「移到左侧／右侧」和「重置浮球位置」。
- 新增或删除楼层、编辑或切换最新楼层的回复、切换角色卡或存档均会恢复原色。改色只作用于当前页面，刷新后也会恢复。
- 尚未加载的 iframe，可滚动到该楼层等待小剧场显示后再点。浏览器隔离的 iframe、纯图片背景和复杂叠层的颜色可能无法正确判断。
